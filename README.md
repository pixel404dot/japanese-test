# Kana Line

Practice hiragana and katakana by gojūon line. Mixed tests from the first five rows (あかさたな), or any line you choose.

**Live site:** [https://pixel404dot.github.io/](https://pixel404dot.github.io/)

Also at [https://pixel404dot.github.io/japanese-test/](https://pixel404dot.github.io/japanese-test/)

## What’s in the drill

- Hiragana, katakana, or a mixed test
- First 5 lines in one tap, or pick any row (including dakuten and combinations)
- Type the reading, choose the character, or shuffle both
- Custom timer per question
- Dark mode
- Chart reference and local progress

## Run locally

This repo also contains the full TanStack Start app (sign-in + saved progress).

```bash
npm install
npm run dev
```

The static GitHub Pages site lives in `docs/` and works without a server.
